# Design System: TermiConnect
**Project ID:** terminal_connection

## 1. Visual Theme & Atmosphere
A clean, modern, and slightly technical atmosphere. It supports both a crisp, airy Light Theme and a high-contrast Dark Theme. Primary blue accents pop against both backgrounds, providing clear hierarchy. The interface utilizes ample whitespace and distinct borders or subtle backgrounds to create structure without heavy shadows. It feels "Utilitarian yet Premium."

## 2. Color Palette & Roles
* **Primary Blue** (#0d33f2) - Used for primary actions, active tabs, icons, and connection status.
* **Light Background** (#f5f6f8) - Main application background in light mode.
* **Dark Background** (#101322) - Main application background in dark mode.
* **Surface Light** (#f1f5f9) - Used for input backgrounds and cards.
* **Border Light** (#e2e8f0) - Used for dividers and subtle card outlines.
* **Text Primary** (#0f172a) - Main text color in light theme.
* **Text Secondary** (#64748b) - Used for labels and secondary information.

## 3. Typography Rules
* **Font Family:** 'Space Grotesk', sans-serif.
* **Headers:** Bold (weight 700), tracking tight for main titles.
* **Labels:** Small text, weight medium (500), uppercase with wide tracking for section headers.
* **Icons:** Material Symbols Outlined.

## 4. Component Stylings
* **Buttons:** 
  * Primary: Solid primary blue background, white bold text, generously rounded (12px to 16px), with a subtle shadow.
  * Secondary/Action: Dashed borders with a lighter surface background.
* **Cards/Containers:** Subtly rounded corners (12px for main cards, 8px for inputs), often carrying a thin 1px border.
* **Inputs/Forms:** Background is a slightly contrasting surface color with thin borders. Icons are inset on the left. Highly readable with ample padding.
* **Navigation:** Bottom tab bar with active items marked by Primary Blue and a small dot indicator above. Inactive items use Text Secondary.

## 5. Layout Principles
* **Spacing:** Generous padding around major sections. Smaller gaps within component clusters.
* **Structure:** Flexbox and grid layouts, often separating content into full-width sections divided by subtle horizontal lines.
